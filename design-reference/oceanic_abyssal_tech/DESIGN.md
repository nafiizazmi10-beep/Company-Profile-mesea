## Brand & Style

The design system embodies the uncharted wonder of deep-sea trenches fused with precision interactive engineering. Built for an ambitious Indonesian studio creating titles across PC, console, and mobile, it presents an aesthetic that feels at once organic and technologically advanced. The tone balances cinematic oceanic immersion with crisp, frictionless utility.

The design movement combines **Glassmorphism** and **Sleek Cyber-Gaming Modernism**:
- Deep oceanic dark-mode canvases that evoke oceanic depths and twilight zones.
- Luminous bioluminescent cyan and aqua accents that function as primary focal points, active states, and interactive feedback.
- Subtle frosted transmissive surfaces, precision hair-line inner strokes, and controlled cyan luminescence simulating submerged instrumentation.
- Uncluttered architecture: High negative space ensures heavy content, complex game telemetry, and marketing media remain digestible and impactful.

## Colors

The palette establishes an authentic oceanic journey from the abyss to bioluminescent light.

### Palette Roles
- **Primary (`#60C1E5` - Vivid Cyan)**: The bioluminescent pulse. Reserved for focal interaction points, hero callouts, active indicators, and high-priority action triggers.
- **Secondary (`#005A9C` - Ocean Blue)**: Mid-depth foundation. Used for structural hierarchy, secondary action fills, interactive states, and deep gradient transitions.
- **Tertiary (`#A0E0EF` - Ice Mist)**: Luminous surface reflections. Used for subtle hover highlights, tertiary data telemetry, icon pings, and atmospheric glows.
- **Neutral Canvas (`#0D1A2D` - Abyssal Navy)**: Root canvas backdrop, providing infinite spatial depth.
- **Surface Elevation (`#13243D` - Trench Layer)**: Container fills, floating panes, and glass backdrop foundations.
- **Primary Navy Structural (`#1B365D`)**: Card borders, dividers, disabled states, and panel foundations.
- **Typography & High Contrast**:
  - Primary Content: `#F0F9FF` (Mist White, 95% opacity against dark surfaces).
  - Secondary Content: `#E0F2FE` (Pale Aqua Ice, 75% opacity).
  - Muted/De-emphasized: Slate cool gray (`#7B93B2`, 55% opacity).
  - Critical/Destructive: `#FF4B72` (Coral Ember).

## Typography

Typography establishes an interplay between geometric game display headers and neutral, legible application text.

- **Headlines (`Sora`)**: Brings forward-looking geometric weight, technical curves, and game-title presence. Headlines utilize negative letter spacing to create unified word shapes.
- **Body Text (`Plus Jakarta Sans`)**: Clean, contemporary grotesque sans with round aperture shapes that harmonize with oceanic curves while maintaining effortless readability across UI dashboards and lore entries.
- **Data & Gaming HUD Indicators (`JetBrains Mono`)**: Applied to badges, version tags, technical telemetry, and metadata chips, grounding the studio's craft in high-precision interactive software.

## Layout & Spacing

The layout is built upon an 8-point rhythmic grid with a fluid responsive shell designed to scale between mobile companion web tools and desktop gaming portals.

- **Desktop (1200px+)**: 12-column layout with `margin: 3rem` (48px) and `gutter: 1.5rem` (24px). Maximum container width rests at 1440px to ensure cinematic presentation without horizontal detachment.
- **Tablet (768px - 1199px)**: 8-column layout with `margin: 2rem` (32px) and `gutter: 1.25rem` (20px). Side rails consolidate into overlay drawers.
- **Mobile (Below 768px)**: 4-column layout with `margin-mobile: 1.25rem` (20px) and `gutter-mobile: 1rem` (16px). Cards collapse horizontally with fluid 100% width stacking.
- **Spacing Rhythm**: Internal component padding follows consistent multiples of 4px and 8px, prioritizing breathing space inside cards (`space-lg` to `space-xl`) to honor oceanic vastness.

## Elevation & Depth

Visual hierarchy uses luminous layering, backdrop dispersion, and targeted bioluminescent casting rather than standard murky black drop shadows.

- **Layer 0 (Canvas)**: Solid deep backdrop `#0D1A2D`.
- **Layer 1 (Submerged Pane)**: Translucent surface `#13243D` at 85% opacity, backdrop blur filter of 16px, bounded by a 1px border of `#1B365D` (40% opacity).
- **Layer 2 (Floating Floating Cards & Sheets)**: Translucent surface `#13243D` at 70% opacity, 24px backdrop blur, bounded by a 1px dual border (top-to-bottom subtle gradient from `#60C1E5` at 20% opacity down to `#1B365D` at 40%). Ambient shadow: `0 12px 32px -4px rgba(6, 13, 24, 0.6)`.
- **Layer 3 (Modals & HUD Overlays)**: Surface `#0D1A2D` at 90% opacity, 32px backdrop blur, elevated with `0 24px 64px -12px rgba(0, 90, 156, 0.25)` and a sharp 1px border in `#60C1E5` (35% opacity).
- **Interactive Luminescence**: Focused elements project an ambient cyan halo: `box-shadow: 0 0 20px 2px rgba(96, 193, 229, 0.35)`.

## Shapes

The interface balances aerodynamic curves with structural stability using `roundedness: 2` (0.5rem base radius).

- **Standard Containers & Cards**: `rounded-lg` (1rem / 16px). This creates organic silhouettes that mimic oceanic contours without compromising data density.
- **Interactive Triggers (Buttons, Inputs)**: `rounded` (0.5rem / 8px). Tighter cornering ensures interactive elements are perceived as solid, responsive controls.
- **Badges, Status Tags & Filter Pills**: Full pill geometry (`rounded-full` / 9999px) to contrast with angular card surfaces.
- **Decorative Elements**: Occasional asymmetric chamfered accents on high-level promotional banners evoke futuristic gaming hardware enclosures.

## Components

### Buttons
- **Primary**: Solid background `#60C1E5` with `#0D1A2D` bold text. On hover, background stays vivid with an active cyan glow (`box-shadow: 0 0 24px rgba(96, 193, 229, 0.5)`) and slight upward translation (-1px).
- **Secondary**: Translucent fill `#005A9C` (25% opacity) over `#13243D`, bordered with 1px `#60C1E5` (40% opacity), text in `#F0F9FF`. Hover increases fill opacity to 45% and border to 80%.
- **Ghost**: Transparent fill, text in `#E0F2FE`. Hover state introduces `#1B365D` (30% opacity) and a soft `#60C1E5` underline glow.

### Cards
- Constructed with high-translucency glass (`#13243D` at 65% opacity, `backdrop-filter: blur(20px)`).
- Rimmed with 1px border `#1B365D` with top highlights in `#60C1E5` (15% opacity).
- Generous internal padding (`space-lg` to `space-xl`).
- Hover states trigger subtle border illumination changes transitioning to `#60C1E5` (45% opacity).

### Chips & Badges
- **Status / Tag Pills**: Full pill radius (`rounded-full`), padding `0.25rem 0.75rem`.
- Background `#1B365D` (40% opacity), 1px stroke `#005A9C` (50% opacity), label rendered in `JetBrains Mono` (`label-code`) in `#A0E0EF`.
- **Live / System Status**: Features an active bioluminescent dot with a pulsating cyan ping animation.

### Form Inputs
- Background `#0D1A2D` (80% opacity), border 1px `#1B365D`.
- Text styled in `#F0F9FF`, placeholder text in `#7B93B2`.
- Focus state applies a 1px border `#60C1E5` along with an inset glow `0 0 10px rgba(96, 193, 229, 0.2)` and canvas ring `0 0 0 2px rgba(96, 193, 229, 0.15)`.

### Checkboxes & Radio Buttons
- Unchecked: Square (`rounded-xs`) or circle with 1.5px border `#1B365D` and background `#0D1A2D`.
- Checked: Fill `#60C1E5` with `#0D1A2D` checkmark icon and ambient cyan micro-glow.

### Gaming HUD Telemetry & Progress Bars
- Rail: 4px or 8px height, `#1B365D` background with 50% opacity.
- Fill: Horizontal linear gradient from `#005A9C` to `#60C1E5` terminating in a sharp 2px light-ice cap (`#A0E0EF`).
